The method arms received the unchanged entrypoint text and license only, with
expectation-bearing files excluded from their staged directory. The raw text is
preserved as data under `method-inputs/`; these files are not an installed-host
discovery record. Full pre-run package fingerprints and subsequent provenance-note
corrections are separate in the result record.

Inputs and finished outputs are retained byte for byte. The source figure is a
coordinator-authored explanation made afterward, not a producer artifact. Supplied
reference previews are modest web images; their physical sharpness is not
certified. Local rendering, source inspection and model review do not establish
real reader comprehension or handwriting comfort.
