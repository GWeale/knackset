# First task: one invitation

Allow one short session, about 10–15 minutes; this is a suggested cap, not a measured completion time. Copy the complete prompt below to a local agent that can write an SVG. No skill installation is needed for this exercise. It does not test package loading or execution of the full Reference Remix skill.

```text
This is a fictional, offline reference-remix exercise. Use only this brief. Do not browse, connect accounts, install anything, send messages, or publish. Write only in a new local folder you choose for this exercise. This prompt is a small authored exercise, not the full Knackset skill or a replay of Night Orchard.

Make one original A6 landscape invitation (148 × 105 mm) for this fictional event. Preserve these words exactly:
Quiet Machines
A listening and drawing workshop
Saturday 14 June / 14:00–16:00
Room 4
Free / bring paper

Three new fictional textual studies (these are NOT Night Orchard’s missing original references):
A. A weather log uses sparse marks and one precise annotation to focus attention. Borrow its selective emphasis; leave its weather symbols behind.
B. A community radio programme makes the time easy to find with two clear typographic levels. Borrow its hierarchy; leave its station identity behind.
C. A seed packet balances one cropped silhouette with generous empty space and clear instructions. Borrow its balance; leave its botanical imagery behind.

First extract one useful principle from each study. Choose one direction and explain what you reject. Then create invitation.svg plus direction.md (at most 150 words). Use at most three colors, system fonts, and no linked fonts, images, scripts, or other external assets. Do not copy any study’s described subject matter. Do not use the Knackset icon as a new design element.

Finish after one concept. Check that the SVG parses, has the intended dimensions, preserves all event words, and has no external assets. If local rendering is available, inspect for clipped text; otherwise say visual checking remains undone. In direction.md distinguish the checks you ran from assumptions and link each chosen design principle to A, B, or C. Stop and report the two local filenames; do not publish them.
```

Human review: inspect the result and name the first unclear instruction. Do not infer that a plausible image proves the full skill was loaded.
