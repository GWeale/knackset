# Make one square companion

A bounded practice task, authored for this packet. It uses the supplied poster as a reference; it is not a replay of its unavailable three original studies and does not include or install the full Reference Remix skill.

**Time box:** about 15 minutes. **Finish:** one editable square SVG plus three short decision notes. No account connection, browser, external reference search, new dependency or publication is needed. Use an existing local editor, or give the prompt below and the included SVG to an already available agent. The files themselves work offline.

Read [the included poster](assets/night-orchard.svg), then copy this prompt:

---

Make one square companion flyer for the fictional Night Orchard event. Use only this brief and `assets/night-orchard.svg` from this packet. Treat the poster as one supplied reference, not as evidence about its original three sources.

The fictional brief: an evening of orchard walks, sound installations and conversations with field scientists. The tone should invite close observation and small discoveries.

Keep these exact text lines, without adding a year, URL, contact, sponsor or invented booking mechanism:

- Night Orchard
- Walks, listening, and small discoveries
- Saturday 18 May / 18:00-23:00
- Alder Field Station
- Free entry / booking required

First identify two principles in the reference worth carrying into a square format, and one visual motif you will leave behind. Distinguish your visible observations from any unknown historical rationale. Then make a materially different composition, not a crop of the portrait poster. Retain clear event facts and the fictional status of this exercise. Leave the original file and icon unchanged.

Deliver `first-pass.svg`, 148 × 148 mm with a `viewBox`, title and description. Use SVG shapes and text with installed/local font fallbacks; no remote fonts, images, scripts or linked assets. Put it in a new local `practice-output/` folder inside this packet; write no other project files. Also deliver `practice-output/NOTES.md` with three short notes: the two principles carried over, what you left behind and why, and what you actually checked. If you cannot render it, say so rather than claiming visual QA. Stop after this one draft.

---

A useful first pass preserves all five text lines, creates a different hierarchy for the square, explains a choice using visible evidence, and opens without fetching anything. It need not be a finished campaign. A human still needs to judge whether the new composition communicates the intended atmosphere; a structurally valid SVG alone cannot settle that.
