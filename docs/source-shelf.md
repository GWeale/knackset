# The source shelf

Inspected 2026-11-01 (America/Los_Angeles): 16 individual skills across 11 repositories.
This is an editorial selection, not a ranking by stars or a claim that these are
universally the best. We read the actual instructions and checked the license
that applied at the linked revision. We have not executed these upstream skills.

Every link below is pinned. Newer revisions may change the method or its terms.
Our packages are original writing; no upstream prose, examples, artwork or code
was bundled. Concept credits do not imply endorsement. Read a source's own setup
and licensing before using it directly.

`LICENSE.txt`; the root license was not used as a substitute. Pstack has a local

nearer license path were checked. Gstack's [third-party notices](https://github.com/garrytan/gstack/blob/a563f476793b61edbb064b853d52cb125a1996c4/NOTICE.md)

automatic permission to reuse every linked asset or dependency.

## How this becomes Knackset

Reference Remix combines reference selection with a visible composition. Story
Mining combines narrative selection with fidelity to the author. Demo Director
combines observable state changes with editing rhythm. Idea Pressure Test combines
fair advocacy with a discriminating experiment. Rabbit Hole applies rival
explanations and source lineage to public questions. Learn by Making uses small
controlled experiments to expose an idea through a working artifact.

Those are our choices, not renamed copies of the source files. Some inspected
ideas remain only on this shelf. A useful source does not obligate us to create
another package. The [contribution bar](workflow-contract.md) explains what would.
