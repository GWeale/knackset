# Knackset identity

Knackset means a set of practical knacks. It was selected from 38 naming directions
for clarity, pronunciation and fit to reusable skills. Handlore was less immediate;
Surelore suggested more certainty than the evidence supports. Exact-name public
GitHub, PyPI, npm and web checks on 2026-11-01 found no obvious software collision.
This is a naming screen, not trademark or domain clearance.

- `knackset-banner.png`: original imagegen raster output, copied unchanged into
  the repository; 1774 × 887 pixels.
- `knackset-social.jpg`: a compact JPEG encoding of that artwork at the same
  dimensions, under 1 MB, used in the README and ready for social-preview upload.
- `knackset-mark.svg`: small native vector mark for project navigation.
- `icon.svg`: original project icon, retained as historical source.
- [Generation prompt](banner-prompt.txt): exact prompt used with the built-in
  imagegen tool. No third-party reference images or vendor logos were used.

The visual uses folded paper to connect packaged know-how with follow-through:
warm ivory, forest ink, yellow-green, and burnt orange. The current wordmark is
**knackset**; the tagline is **Agent skills with follow-through.**

Referencing the social image in the README does not configure GitHub's repository
social preview. GitHub accepts PNG/JPG/GIF under 1 MB and recommends 1280 × 640
for best display. This export retains the same 2:1 aspect ratio at a larger size.
[Official upload guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)

Original license notices retain the project's former name to preserve attribution.
Current documentation, installation URLs and repository identity use Knackset.
