# Synthetic production brief: Quiet Ledger

The supplied quiet-ledger.html is a small real runnable artifact with entirely
synthetic data. It uses no network, dependencies, account, or persistent storage.
Inspect its source and, when an authorized local preview is available, its output.
Do not describe source inspection as an observed filmed interaction.

Make a 35-45 second silent demo for a person who wants to inspect a small expense
list. The key proof: selecting Repairs hides Parts and changes the shown total
from $187.00 across four records to $140.00 across two records. The viewer should
understand which records the total includes. Filtering is reversible.

Secondary capability: Export shown rows downloads a CSV of the currently visible
records. It does not upload data. Cloud sync is visibly disabled and unimplemented.
The artifact starts with fixture data; it does not implement file import.

Deliver a timed script, storyboard, captions, and an editable local HTML animatic
that honestly represents the fixture. Clearly label any simulated interaction.
If already available local tools can make an MP4 without installation, produce and
inspect it too; otherwise identify that missing step. No GUI is required for the
source deliverable. Use an evaluator-supplied temporary output directory.
